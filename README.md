- 비개발자의 요청을 듣고 **실제로 사용할 수 있는 화면과 기능**으로 옮기는 일을 좋아합니다.

- 주문·관리자 화면의 API 연동과 AWS 배포를 경험하며, 화면 너머의 서비스 흐름도 익히고 있습니다.

### 대표 프로젝트

#### KUAD 2026 · ALTER EGO

**건국대학교 의상디자인학과 졸업전시 웹사이트**

[사이트 보기](https://kuadarchive.com/2026/) · [소스 코드](https://github.com/jayyeong/ALTEREGO_2026_VITE) · [개선 기록](https://github.com/jayyeong/ALTEREGO_2026_VITE/pull/27)

작품과 사람을 소개하는 전시 페이지부터 룩북·런웨이, 굿즈 주문과 관리자 화면까지 담은 프로젝트입니다. React와 Vite로 구성하고, GitHub Actions를 통해 S3·CloudFront로 배포합니다.

| 관심을 두고 구현한 부분 | 내용 |
| :--- | :--- |
| 이미지 탐색 | 썸네일과 원본 분리, 지연 로딩, 전체 화면 보기와 키보드 탐색 |
| 주문과 운영 | 주문 입력 검증, API 연동, 입금·품절 상태 관리, 엑셀 다운로드 |
| 배포 | 빌드·업로드 자동화와 파일별 캐시 정책 설정 |

### 사용한 기술

| 분야 | 기술 |
| :--- | :--- |
| Frontend | JavaScript · React · React Router · Tailwind CSS · Vite |
| Deployment | AWS S3 · CloudFront · Route 53 · GitHub Actions |
| Backend 경험 | Spring Boot · JPA · MySQL · REST API |
| Computer Vision 경험 | Python · OpenCV · YOLOv8 |
